🖱️ Gesture Control Virtual Mouse Instructions

How to Use the Virtual Mouse

  • 👉 Cursor Movement: Move your index finger
  • 🖐️ Left Click: Index + middle finger
  • ✌️ Right Click: Thumb + pinky
  • 🤏 Double Click: Index + middle + ring finger
  • 📜 Scroll Up: Middle + ring + pinky
  • 🔽 Scroll Down: Index + ring
  • 💡 Brightness Control: Thumb + index pinch
  • 🔊 Volume Control: Thumb + index + middle pinch
  • 🤏 Drag and drop Click: Thumb + Index finger
